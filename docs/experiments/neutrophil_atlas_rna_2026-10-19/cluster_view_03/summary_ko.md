# 클러스터별 최고 점수 후보

- 원 세포 263,159개·92/51개 클러스터·UMAP을 그대로 사용했다. 비교 대상은 호중구 6단계 패널이다.
- 점수: 각 세포의 정규화한 마커 RNA 값을 평균한 뒤, 검출되지 않은 세포도 포함해 클러스터 전체에서 평균했다.
- 그림 A: 클러스터별 1위 단계를 색으로, 클러스터 ID를 숫자로 표시. 그림 B: 단계별 최고점 클러스터에 검은 테 표시.
- 1위·2위·점수 차이: cluster_candidates.csv. 전체 점수: cluster_scores.csv. 단계별 최고: stage_peak_clusters.csv.

| 단계 | 최고점 클러스터(p92) | 원저자 주석의 최다 유형(사후 비교) |
|---|---:|---|
| Myeloblast | 73 | HSC 77.7% |
| PM | 31 | GMP-Neut 80.2% |
| MY·MM·SN | 85 | Stromal 100% |
| BN | 8 | NK 94.0% |

- MY·MM이 클러스터 내부 1위인 곳은 두 해상도 모두 0개다. 해당 세포의 부재를 뜻하지 않으며, 현재 패널 평균 점수의 구별 한계다.
- 동일 공여자 block에 같은 비중을 주면 1위가 p92에서 4개, p51에서 5개 달라진다. p92의 4세포 군집은 이 보조 평균을 계산할 수 없어 결측으로 남겼다.
- 검증: 테스트 21개/222항목 통과. 858개 클러스터×단계 평균·검출률과 후보·최고점을 독립 검산했다. 기존 결과 40개 파일을 보존했다.
- 별도 실험 브랜치만 갱신한다. 변경 전 기준 f0fea85. 확정 세포 유형·정확도·분화 경로를 주장하지 않으며 기본 모델에 병합하지 않았다.
- 최종 결과: cluster_view_03. 앞선 결과의 계산값과 원본 UMAP은 보존했다.
